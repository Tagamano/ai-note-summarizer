01 / 做了什麼

從文章到摘要，
保留值得記住的內容。

這是一個以 Python 製作的命令列筆記工具。使用者貼上多行文章後，程式透過 requests 呼叫本機 Ollama API，請 qwen2.5:3b 以繁體中文產生三個重點與一句話總結。

01

多行文章輸入

直接貼上筆記或文章，以獨立一行的 /end 完成輸入。

02

即時串流顯示

逐行解析 JSON Lines，在終端逐段顯示模型產生的文字。

03

本機模型處理

文章送至本機 Ollama；目前程式不會儲存文章或摘要。

02 / 怎麼執行

準備環境，
開始第一份摘要。

以下以 Windows PowerShell 為例。
摘要程式在自己的電腦執行。

  1. 1

    安裝 Python、uv 與 Ollama

    從 Python 官網安裝 Python 3.9 以上，並確認 Python 已加入 PATH。依 uv 官方安裝說明安裝 uv；可使用下方 WinGet 指令。再從 Ollama 官網下載並安裝應用程式。安裝後重新開啟終端。

    winget install --id=astral-sh.uv -e
python --version
uv --version
ollama --version
  2. 2

    下載專案並同步依賴

    在 GitHub 專案頁選擇 Code → Download ZIP，解壓縮後於專案資料夾開啟 PowerShell。專案已設定 requests 依賴，直接同步即可。

    cd 你的專案路徑\ai-note-summarizer
uv sync
  3. 3

    啟動本機模型

    開啟 Ollama 應用程式，再下載模型。若服務尚未啟動，可在另一個終端執行 ollama serve；已啟動時不用重複執行。

    ollama pull qwen2.5:3b
  4. 4

    執行並輸入文章

    uv run python main.py

    貼上多行文章，最後單獨輸入 /end 並按 Enter。等待終端顯示三個重點與一句話總結，再自行核對原文。首次載入模型可能較慢。
